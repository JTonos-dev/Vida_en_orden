# Seeds de demostración

Los datos de esta carpeta son ficticios y sirven únicamente para pruebas/manuales de una instalación local. No se aplican automáticamente a D1 ni representan datos de ningún usuario.

La aplicación usa las migraciones de `drizzle/` para crear el esquema. Un seed operativo debe adaptarse a la versión del esquema y ejecutarse solo contra una base de prueba.
